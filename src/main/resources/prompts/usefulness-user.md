## Task: usefulnessAssessor

Assess how useful this contribution is for the project.

{{PrOverview}}

Triage:
{{PrSummary}}

Consider whether the change solves a real, stated problem; whether it matches the linked issue, if any; whether its value is proportionate to its size and risk; and whether a maintainer would want it. Return:
- score: 0.0 to 10.0, where 9 means clearly valuable and well targeted, 6 useful with reservations, 3 of doubtful value, 0 harmful or unwanted;
- rationale: two or three sentences;
- matchesLinkedIssue: true only when a linked issue exists and the change addresses it;
- concerns: short phrases, empty when there are none.
